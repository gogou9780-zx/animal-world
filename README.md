# ระบบสมัครสมาชิก (เว็บไซต์ + Google Sheet)

โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้า Home เว็บความรู้เรื่องสัตว์ มีสัตว์เด่น 6 ชนิดและปุ่มไปหน้าอื่น |
| `animals.html` | หน้าสัตว์น่ารู้ 40 ชนิด 6 กลุ่ม มีช่องค้นหาและปุ่มกรองกลุ่ม |
| `assets/*.svg` | ภาพวาดสำรอง ใช้แทนเมื่อรูปถ่ายโหลดไม่ได้ (`placeholder.svg` ใช้กับสัตว์ที่ไม่มีภาพวาดเฉพาะ) |
| `register.html` | หน้าสมัครสมาชิก สมัครผ่าน Supabase Auth สมัครสำเร็จแล้วมีปุ่มไปเมนูสมาชิก |
| `member.html` | เมนูสมาชิก (ต่างจากหน้าแรก) ทักทายด้วยชื่อ แสดงรหัสสมาชิก มีเมนูและเรื่องน่ารู้ประจำวัน |
| `animal-detail.js` | คลิกการ์ดสัตว์เพื่อเปิดหน้าต่างข้อมูลสัตว์ (ภาพใหญ่ กลุ่ม ความรู้ ลิงก์ Wikipedia และที่มาภาพ) |
| `quiz.html` | แบบทดสอบสัตว์ 6 ข้อ เข้าจากเมนูสมาชิก |
| `member.js` | จำชื่อและรหัสสมาชิกในเบราว์เซอร์ และเปลี่ยนปุ่มสมัครเป็น "เมนูสมาชิก" |
| `style.css` | สไตล์ที่ใช้ร่วมกัน |
| `supabase-config.js` | ค่าเชื่อมต่อ Supabase |
| `supabase-setup.sql` | SQL สร้างตารางสมาชิก ทริกเกอร์ และ RLS |

## ขั้นตอนติดตั้ง (Supabase)

### 1) สร้างตารางและทริกเกอร์
เปิด Supabase Dashboard > **SQL Editor** แล้ววางโค้ดจากไฟล์ `supabase-setup.sql` ทั้งหมด กด Run (ทำครั้งเดียว) จะได้ตาราง `members`, รหัสสมาชิกอัตโนมัติ (M0001, M0002, ...), กันเบอร์โทรซ้ำ และเปิด RLS

### 2) ตั้งค่า Auth
- **Authentication > Providers > Email** ต้องเปิดใช้งาน
- ถ้าอยากให้สมัครแล้วเข้าใช้ได้ทันที ให้ปิด **Confirm email** (ถ้าเปิดไว้ ผู้สมัครต้องกดลิงก์ในอีเมลก่อนจึงเข้าสู่ระบบได้)

### 3) ใส่ค่าเชื่อมต่อ
แก้ `supabase-config.js` ให้เป็น Project URL และ anon/publishable key ของโปรเจกต์ (ห้ามใส่ service_role key)

### 4) ทดสอบ
เปิด `index.html` สมัครสมาชิก แล้วดูแถวใหม่ที่ Table Editor > `members` และผู้ใช้ที่ Authentication > Users

### 5) นำขึ้นเว็บจริง
อัปโหลดไฟล์ HTML/CSS/JS ทั้งหมดและโฟลเดอร์ `assets` ไว้ที่เดียวกัน เช่น GitHub Pages, Netlify, Cloudflare Pages

### บังคับให้สมาชิกเปลี่ยนรหัสผ่าน
ตั้งค่า `must_change = true` ในแถวของสมาชิกที่ตาราง `members` ครั้งต่อไปที่เข้าสู่ระบบจะถูกพาไปหน้าเปลี่ยนรหัสผ่านก่อน

### ส่วนที่เห็นเฉพาะสมาชิก
- เมนู "สัตว์น่ารู้", ส่วนสัตว์เด่นในหน้าแรก และหน้า `animals.html` แสดงเฉพาะผู้ที่สมัครหรือเข้าสู่ระบบแล้ว ผู้เยี่ยมชมจะเห็นปุ่มเข้าสู่ระบบ/สมัครแทน
- อยากซ่อนส่วนอื่นด้วย ให้ใส่ `data-member-only` ที่แท็กนั้น
- นี่เป็นการซ่อนที่หน้าเว็บ ข้อมูลสัตว์ยังอยู่ในไฟล์ HTML/JS ที่คนเปิดดูซอร์สโค้ดได้ ถ้าต้องการปกป้องจริง ต้องย้ายข้อมูลสัตว์ไปไว้ในตาราง Supabase ที่ตั้ง RLS ให้เฉพาะผู้ล็อกอินอ่านได้

### คลิกสัตว์เพื่อดูข้อมูล
คลิกที่ภาพหรือชื่อสัตว์ (หน้าแรกและหน้าสัตว์น่ารู้) จะเปิดหน้าต่างข้อมูล เลื่อนไปสัตว์ตัวก่อนหน้า/ถัดไปได้ ปิดด้วยปุ่ม × คลิกพื้นหลัง หรือกด Esc การ์ดสัตว์ใหม่ต้องมี `data-file` (หน้า `animals.html` ใส่ให้อัตโนมัติจากค่า `file`)

### เรื่องเมนูสมาชิก
- การเข้าสู่ระบบใช้ Supabase Auth (รหัสผ่านถูกเข้ารหัสโดย Supabase) เข้าสู่ระบบได้จากทุกเครื่องด้วยอีเมลและรหัสผ่าน
- localStorage เก็บแค่ชื่อและรหัสสมาชิกไว้แสดงผล ส่วนสถานะล็อกอินจริงตรวจจาก session ของ Supabase

### วิธีเพิ่มสัตว์ในหน้าสัตว์น่ารู้
เปิด `animals.html` แล้วหาตัวแปร `ANIMALS` คัดลอกสัตว์หนึ่งตัวมาต่อท้าย แล้วแก้ค่า `name` (ชื่อ), `group` (กลุ่ม: mammal, bird, reptile, amphibian, fish, invertebrate) และ `fact` (ความรู้สั้น ๆ) ส่วนรูปเลือกได้ 2 แบบ
- `wiki: "Lion"` ใส่ชื่อบทความภาษาอังกฤษบน en.wikipedia.org (ดูจากลิงก์ เช่น `.../wiki/Polar_bear` ใส่ `"Polar bear"`) ระบบจะดึงภาพหลักของบทความมาให้เอง ไม่ต้องหาชื่อไฟล์ แนะนำแบบนี้
- `file: "ชื่อไฟล์.jpg"` ใช้ชื่อไฟล์บน Wikimedia Commons (ส่วนหลัง `File:` ในลิงก์หน้าไฟล์) ถ้าต้องการเลือกภาพเอง

ปุ่มกรอง จำนวนสัตว์ในหน้า `animals.html` และรายการเครดิตรูปจะอัปเดตเอง และสัตว์จะถูกเรียงตามกลุ่มให้อัตโนมัติ ส่วนตัวเลข "40 ชนิด" ในข้อความของ `index.html` ต้องแก้เองถ้าเพิ่มสัตว์อีก

### เรื่องรูปถ่ายสัตว์
- รูปถ่ายดึงตรงจาก Wikimedia Commons (ใบอนุญาตเปิด) ถ้ารูปโหลดไม่ได้ เว็บจะใช้ภาพวาดในโฟลเดอร์ `assets` แทนอัตโนมัติ
- ก่อนเปิดเว็บจริง ควรเปิดลิงก์ "ที่มาของภาพถ่าย" ท้ายหน้าแรกทีละรูป เพื่อตรวจใบอนุญาตและชื่อผู้ถ่ายภาพ (บางใบอนุญาตกำหนดให้ระบุเครดิต)
- เพื่อให้เว็บเร็วและเสถียร แนะนำให้ดาวน์โหลดรูปมาเก็บในโฟลเดอร์ของเว็บเอง แล้วแก้ `src` ในไฟล์ HTML ให้ชี้ไปที่ไฟล์นั้น

## หมายเหตุ
- ระบบกันอีเมลซ้ำ (Supabase Auth) และเบอร์โทรซ้ำ (unique ในตาราง `members`) และสร้างรหัสสมาชิกอัตโนมัติ
- มีช่องดักบอท (honeypot) และตรวจสอบข้อมูลฝั่งหน้าเว็บ
- RLS ทำให้สมาชิกอ่านได้เฉพาะข้อมูลของตัวเอง ควรจำกัดคนที่เข้า Supabase Dashboard
- ควรแสดงนโยบายความเป็นส่วนตัวจริงตามกฎหมาย PDPA
