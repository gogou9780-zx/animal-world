# ระบบสมัครสมาชิก (เว็บไซต์ + Google Sheet)

โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้า Home เว็บความรู้เรื่องสัตว์ มีสัตว์เด่น 6 ชนิดและปุ่มไปหน้าอื่น |
| `animals.html` | หน้าสัตว์น่ารู้ 20 ชนิด 6 กลุ่ม มีช่องค้นหาและปุ่มกรองกลุ่ม |
| `assets/*.svg` | ภาพวาดสำรอง ใช้แทนเมื่อรูปถ่ายโหลดไม่ได้ (`placeholder.svg` ใช้กับสัตว์ที่ไม่มีภาพวาดเฉพาะ) |
| `register.html` | หน้าสมัครสมาชิก ส่งข้อมูลไป Google Sheet สมัครสำเร็จแล้วมีปุ่มไปเมนูสมาชิก |
| `member.html` | เมนูสมาชิก (ต่างจากหน้าแรก) ทักทายด้วยชื่อ แสดงรหัสสมาชิก มีเมนูและเรื่องน่ารู้ประจำวัน |
| `quiz.html` | แบบทดสอบสัตว์ 6 ข้อ เข้าจากเมนูสมาชิก |
| `member.js` | จำชื่อและรหัสสมาชิกในเบราว์เซอร์ และเปลี่ยนปุ่มสมัครเป็น "เมนูสมาชิก" |
| `style.css` | สไตล์ที่ใช้ร่วมกัน |
| `Code.gs` | สคริปต์ Google Apps Script รับข้อมูลแล้วเขียนลง Sheet |

## ขั้นตอนติดตั้ง

### 1) สร้าง Google Sheet และสคริปต์
1. สร้าง Google Sheet ใหม่ (ตั้งชื่ออะไรก็ได้)
2. เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. ลบโค้ดเดิม แล้ววางโค้ดจากไฟล์ `Code.gs` ทั้งหมด กดบันทึก

### 2) Deploy เป็น Web App
1. กด **Deploy > New deployment**
2. กดไอคอนเฟือง เลือกประเภท **Web app**
3. ตั้งค่า
   - Execute as: **Me**
   - Who has access: **Anyone**
4. กด Deploy แล้วอนุญาตสิทธิ์ (Authorize) ตามที่ระบบถาม
5. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

### 3) ใส่ URL ในหน้าสมัครสมาชิก
เปิด `register.html` แล้วแก้บรรทัดนี้

```js
const SCRIPT_URL = "PASTE_YOUR_WEB_APP_URL_HERE";
```

ให้เป็น URL ที่คัดลอกมา

### 4) ทดสอบ
เปิด `index.html` ในเบราว์เซอร์ กดสมัครสมาชิก กรอกข้อมูล แล้วดูว่ามีแถวใหม่ในชีต `Members` (ชีตและหัวคอลัมน์จะถูกสร้างให้อัตโนมัติ)

### 5) นำขึ้นเว็บจริง
อัปโหลด `index.html`, `register.html`, `style.css` และโฟลเดอร์ `assets` ไปไว้ที่เดียวกัน (โครงสร้างโฟลเดอร์ต้องคงเดิม) เช่น GitHub Pages, Netlify, Cloudflare Pages หรือโฮสติ้งทั่วไป

### เรื่องเมนูสมาชิก
- หลังสมัครสำเร็จ เบราว์เซอร์จะจำชื่อและรหัสสมาชิกไว้ (เก็บใน localStorage ไม่เก็บอีเมลหรือเบอร์โทร) แล้วเมนูสมาชิกจึงเปิดได้
- นี่ไม่ใช่ระบบล็อกอินจริง เพราะ Google Sheet ไม่มีรหัสผ่าน ใครที่เปิดจากเบราว์เซอร์อื่นจะไม่เห็นเมนู แต่ก็ไม่ได้ป้องกันการเข้าถึงอย่างปลอดภัย ห้ามนำเนื้อหาที่เป็นความลับหรือเก็บเงินไปไว้ในหน้านี้
- ถ้าต้องการให้สมาชิกล็อกอินกลับเข้ามาได้จากเครื่องอื่น ต้องเพิ่มระบบล็อกอิน (เช่น รหัสผ่านหรือลิงก์ส่งทางอีเมล) ซึ่งต้องออกแบบเพิ่ม

### วิธีเพิ่มสัตว์ในหน้าสัตว์น่ารู้
เปิด `animals.html` แล้วหาตัวแปร `ANIMALS` คัดลอกสัตว์หนึ่งตัวมาต่อท้าย แล้วแก้ค่า `name` (ชื่อ), `group` (กลุ่ม: mammal, bird, reptile, amphibian, fish, invertebrate), `fact` (ความรู้สั้น ๆ) และ `file` (ชื่อไฟล์รูปบน Wikimedia Commons คือส่วนหลัง `File:` ในลิงก์หน้าไฟล์) ปุ่มกรอง จำนวนสัตว์ และรายการเครดิตรูปจะอัปเดตเอง ถ้าเพิ่มสัตว์ อย่าลืมแก้ตัวเลข "20 ชนิด" ในข้อความของ `index.html` และ `animals.html` ด้วย

### เรื่องรูปถ่ายสัตว์
- รูปถ่ายดึงตรงจาก Wikimedia Commons (ใบอนุญาตเปิด) ถ้ารูปโหลดไม่ได้ เว็บจะใช้ภาพวาดในโฟลเดอร์ `assets` แทนอัตโนมัติ
- ก่อนเปิดเว็บจริง ควรเปิดลิงก์ "ที่มาของภาพถ่าย" ท้ายหน้าแรกทีละรูป เพื่อตรวจใบอนุญาตและชื่อผู้ถ่ายภาพ (บางใบอนุญาตกำหนดให้ระบุเครดิต)
- เพื่อให้เว็บเร็วและเสถียร แนะนำให้ดาวน์โหลดรูปมาเก็บในโฟลเดอร์ของเว็บเอง แล้วแก้ `src` ในไฟล์ HTML ให้ชี้ไปที่ไฟล์นั้น

## หมายเหตุ
- **แก้โค้ด `Code.gs` ภายหลัง** ต้อง Deploy > Manage deployments > Edit > New version ทุกครั้ง URL เดิมจึงใช้เวอร์ชันใหม่
- ระบบกันอีเมลและเบอร์โทรซ้ำ และสร้างรหัสสมาชิกอัตโนมัติ (M0001, M0002, ...)
- มีช่องดักบอท (honeypot) และตรวจสอบข้อมูลทั้งฝั่งหน้าเว็บและฝั่งสคริปต์
- ข้อมูลส่วนบุคคลของลูกค้า ควรจำกัดคนที่เข้าถึงชีต และแสดงนโยบายความเป็นส่วนตัวจริงของร้านตามกฎหมาย PDPA
- ทุกคนที่รู้ URL ของ Web App สามารถส่งข้อมูลเข้าได้ แต่ไม่สามารถอ่านข้อมูลออกมาได้
